# backend-interview-lab

10주 대기업 백엔드 기술면접 실습용 누적 프로젝트입니다.

## Day 1

- Java 25 LTS / Spring Boot 4.1.1 / Gradle 9.7.1
- 고정 데이터셋 v1.0.0
- 시간복잡도, Array, ArrayList 실습

## 실행

1. JDK 25 확인: `java -version`
2. Gradle 9.7.1이 설치되어 있다면 wrapper 생성: `gradle wrapper --gradle-version 9.7.1`
3. 테스트: `./gradlew test` (Windows: `gradlew.bat test`)
4. 애플리케이션: `./gradlew bootRun`

강의자료는 `docs/day-01.md`를 참고하세요.
