# Day 5 Git Flow Drill

이 폴더는 Day 5 Git 실습용 **Starter**다.

## 중요

- `.git` 폴더는 제공되지 않는다.
- `git init -b main`부터 직접 수행한다.
- `reservation-rules.md`와 `PR_DRAFT.md`의 TODO는 직접 해결한다.
- 완성된 정답 문서는 제공하지 않는다.

## 목표

```text
init
→ initial commit
→ branch
→ rule clarification commit
→ PR draft commit
→ diff review
→ tag
```

자세한 순서는 `lessons/day005/lecture.md`와 `practice.md`를 따른다.
