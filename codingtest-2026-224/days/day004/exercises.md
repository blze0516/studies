# 초급 1 — 첫 번째 숫자

## 문제

정수 N개가 주어진다. 첫 번째 숫자를 출력하라.

## 입력 예시

```text

```

## 출력 예시

```text

```

## 제한

```text
1 <= N <= 100000

```

## 풀이 전 질문

- 첫 번째 원소의 인덱스는 무엇인가?

# 고급 4 — 가장 큰 상승량

## 문제

정수 N개가 주어진다.

서로 이웃한 두 값에서 뒤의 값이 더 큰 경우에만 상승량을 계산한다.

가장 큰 상승량을 출력하라.

상승한 구간이 하나도 없으면 0을 출력한다.

## 입력 예시

```text
6
10 13 8 20 19 25
```

## 출력 예시

```text
12
```

`8`에서 `20`으로 올라갈 때 상승량이 12로 가장 크다.

## 풀이 전 질문

- 현재 원소와 다음 원소를 함께 보려면 어떤 순회가 필요한가?
- 상승하지 않은 경우를 어떻게 처리할 것인가?

# 고급 5 — 최댓값을 제외한 합

## 문제

정수 N개가 주어진다.

전체 합에서 **최댓값 하나만 제외한 합**을 출력하라.

최댓값이 여러 번 등장하더라도 하나만 제외한다.

## 입력 예시

```text
5
10 20 20 5 3
```

## 출력 예시

```text
38
```

전체 합 58에서 최댓값 20 하나만 뺀 결과다.

## 풀이 전 질문

- 전체 합과 최댓값을 한 번의 순회에서 동시에 구할 수 있는가?
- 최댓값이 중복되어도 왜 한 번만 빼면 되는가?

# 제출 전 공통 체크리스트

- [ ] 입력 제한을 읽었다.
- [ ] 리스트 길이가 최소 1인지 확인했다.
- [ ] 첫 번째 인덱스는 0이라고 기억했다.
- [ ] 마지막 인덱스는 N - 1이라고 기억했다.
- [ ] `i + 1`을 쓴 문제는 반복 범위를 다시 확인했다.
- [ ] 합계 변수는 반복문 밖에서 초기화했다.
- [ ] 최소/최대 초기값은 입력의 첫 원소를 사용했다.
- [ ] `N = 1` 또는 최소 N을 테스트했다.
- [ ] 모두 같은 값도 테스트했다.
- [ ] 음수 입력이 가능한 문제는 음수만 있는 반례도 테스트했다.
