# Day 1 Exercises

정답은 포함하지 않는다. 모든 문제는 Day 1 범위인 **입출력, 사칙연산, 비교, 조건문, 아주 기초적인 반복/복잡도 감각** 안에서 해결하도록 설계했다.

## 풀이 공통 규칙

각 문제를 풀기 전에 코드 위에 주석으로 다음 세 줄을 적는다.

```text

# 핵심 조건:
# 예상 시간복잡도:
```

## 고급 5 — 복잡도 분류 퀴즈

정수 N이 주어진다고 하자. 아래 네 코드 조각 각각의 시간복잡도를 `O(1)`, `O(N)`, `O(N²)` 중에서 고르라. 코드 작성 문제는 아니며 `review.md`에 답을 기록한다.

### A

```python
print(n + 1)
```

### B

```python
for i in range(n):
    print(i)
```

### C

```python
for i in range(n):
    for j in range(n):
        print(i, j)
```

### D

```python
count = 0
for i in range(n):
    count += 1
print(count)
```

### 추가 질문

B와 D의 출력량은 다르지만, 핵심 반복 횟수 기준 Big-O는 어떻게 비교되는가?
