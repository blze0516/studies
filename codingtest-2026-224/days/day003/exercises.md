# 초급 1 — 절댓값 함수

## 문제

정수 `N`이 주어진다. `get_absolute(n)` 함수를 만들어 `N`의 절댓값을 반환하고 출력하라.

## 입력 예시

```text
-7
```

## 출력 예시

```text
7
```

## 제한

```text
-1000000 <= N <= 1000000
```

## 조건

오늘은 `abs()`를 사용하지 않고 조건문으로 직접 구현한다.

## 풀이 전 질문

- 함수의 매개변수는 무엇인가?
- `N = 0`일 때 결과는 무엇인가?

# 고급 5 — 세 단계 주문 처리

## 문제

상품 가격 `price`, 수량 `quantity`, 쿠폰 할인율 `discount`, 가진 돈 `money`가 주어진다.

다음 함수를 각각 만든다.

```text
get_total_price
get_discounted_price
can_pay
```

처리 순서:

```text
상품 가격 × 수량
→ 할인 적용
→ 가진 돈으로 결제 가능한지 판정
```

결제 가능하면 최종 가격을 출력하고, 불가능하면 `NO`를 출력하라.

## 입력 예시

```text
3000 3 10 9000
```

## 출력 예시

```text
8100
```

## 제한

```text
0 <= price <= 1000000
1 <= quantity <= 100000
0 <= discount <= 100
0 <= money <= 100000000000
```

## 풀이 전 질문

- 각 함수는 정확히 한 가지 역할만 맡고 있는가?
- 함수의 반환값이 다음 함수의 입력으로 어떻게 연결되는가?
- 전체 시간복잡도는 함수가 세 개라서 더 커지는가?
