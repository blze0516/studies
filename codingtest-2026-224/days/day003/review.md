# 오늘 외울 템플릿 여부

## 값을 계산해서 반환

```python
def calculate(value):
    result = value * 2
    return result
```

## 조건 판정

```python
def is_valid(value):
    return value >= 0
```

## N개 순회 후 결과 반환

```python
def get_total(numbers):
    total = 0

    for number in numbers:
        total += number

    return total
```

문법을 외우는 것보다 먼저 다음을 말할 수 있어야 한다.

```text
입력은 무엇인가?
함수의 책임은 무엇인가?
무엇을 반환하는가?
```

# 오늘의 시간복잡도

| 형태 | 복잡도 | 이유 |
|---|---|---|
| 비교 몇 번 | `O(1)` | 작업 횟수가 일정함 |
| 계산 몇 번 | `O(1)` | 입력 크기와 무관한 고정 연산 |
| N개 한 번 순회 | `O(N)` | 각 원소를 한 번 확인 |
| O(N) 함수 두 개 순차 실행 | `O(N)` | `O(2N)`에서 상수 배를 생략 |

함수를 여러 개 만들었다는 이유만으로 복잡도가 나빠지는 것은 아니다.

# 오늘의 핵심 반례

## 반례 1 — 정확한 조건 경계

60 이상이면 `60`을 반드시 테스트한다.

## 반례 2 — 최소 입력 크기

리스트 문제라면 `N = 1`을 확인한다.

## 반례 3 — 조건 만족 0개

카운트 함수가 0을 정상 반환하는지 확인한다.

## 반례 4 — 조건 전부 만족

카운트가 정확히 N까지 올라가는지 확인한다.

## 반례 5 — 인자 순서

```python
get_final_price(price, discount)
```

를 실수로 다음처럼 호출하지 않았는지 확인한다.

```python
get_final_price(discount, price)
```
