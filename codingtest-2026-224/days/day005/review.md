## 오늘 틀리기 쉬운 부분

- [ ] 문자열 인덱스도 0부터 시작한다.
- [ ] 길이가 N이면 마지막 인덱스는 N - 1이다.
- [ ] `split()`의 결과가 List라는 것을 기억한다.

- [ ] `replace`가 원본 문자열을 직접 수정하지 않는다는 것을 안다.
- [ ] `count`는 개수를 반환한다.
- [ ] `index`는 첫 위치를 반환한다.
- [ ] 존재하지 않을 수 있는 값을 `index`로 바로 찾지 않는다.
- [ ] 빈 문자열 `""`과 공백 `" "`을 구분한다.
- [ ] 문자열을 숫자로 바꿀 필요가 있는 문제인지 먼저 확인한다.

# 오늘의 핵심 산출물 — 문자열 내장함수 정리

아래 표를 직접 한 번 다시 작성한다.

| 기능 | 기본 형태 | 반환 결과 | 언제 사용 | 대표 실수 |
|---|---|---|---|---|
| 나누기 | `text.split()` | List | 단어/구분자 분리 | 결과를 문자열로 착각 |
| 자르기 | `text[a:b]` | String | 일부 구간 필요 | 끝 위치 포함으로 착각 |
| 바꾸기 | `text.replace(x, y)` | String | 문자/부분 문자열 치환 | 반환값 저장 안 함 |
| 개수 | `text.count(x)` | int | 등장 횟수 필요 | 위치라고 착각 |
| 위치 | `text.index(x)` | int | 첫 등장 위치 필요 | 없는 값 조회 |

# 메서드 선택 훈련

다음 상황에서 사용할 기능을 바로 말해 본다.

```text
문장을 단어로 나눈다
→ split

앞 3글자만 필요하다
→ slice

하이픈을 없앤다
→ replace

a가 몇 개인지 센다
→ count

첫 a의 위치가 필요하다
→ index
```

# 오늘 외울 템플릿 여부

## 공백 기준 나누기

```python
words = text.split()
```

## 특정 구분자 기준 나누기

```python
parts = text.split("-")
```

## 슬라이스

```python
part = text[start:end]
```

## 치환

```python
changed = text.replace("old", "new")
```

## 개수

```python
count_value = text.count("a")
```

## 안전한 첫 위치

```python
if target in text:
    position = text.index(target)
else:
    position = -1
```

코드 모양 자체보다 **어떤 상황에서 고르는지**를 설명할 수 있어야 한다.

# 오늘의 시간복잡도

문자열 길이를 N이라고 할 때:

| 작업 | 대표 시간복잡도 | 기억할 점 |
|---|---:|---|
| 인덱스 접근 | `O(1)` | 특정 위치 바로 접근 |
| 전체 순회 | `O(N)` | 문자 N개 확인 |
| `split` | `O(N)` | 문자열 전체를 나눔 |
| `replace` | `O(N)` | 대상 확인 및 새 문자열 생성 |
| `count` | `O(N)` | 전체에서 등장 확인 |
| `index` | 최악 `O(N)` | 앞에서부터 탐색 |
| 길이 K slice | `O(K)` | K길이 결과 생성 |

내장 함수를 썼다고 해서 연산 비용이 0이 되는 것은 아니다.

# 오늘의 핵심 반례

## 반례 1 — 한 글자

```text
a
```

첫 문자와 마지막 문자가 같다.

## 반례 2 — 찾는 문자가 없음

```text
hello
z
```

`index`를 바로 호출하면 안 된다.

## 반례 3 — 여러 공백

```text
red   blue
```

일반 단어 분리에서는 `split()`을 확인한다.

## 반례 4 — 바꿀 대상 없음

```text
abcdef
```

`replace` 결과는 원본과 같은 내용이 될 수 있다.

## 반례 5 — slice보다 짧은 문자열

```text
abc
```

`text[:5]`는 가능한 범위까지만 가져온다.

## 반례 6 — 대상이 첫 위치

```text
apple
a
```

첫 인덱스는 0이다.
