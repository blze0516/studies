# 초급 5문제

## 초급 1 — 양끝 문자

## 문제

문자열 하나가 주어진다. 첫 문자와 마지막 문자를 붙여서 출력하라.

## 입력 예시

```text
python
```

## 출력 예시

```text
pn
```

## 조건

문자열 길이는 1 이상이다.

## 풀이 전 질문

- 첫 인덱스는 무엇인가?
- 길이가 1일 때 첫 문자와 마지막 문자는 어떻게 되는가?

---

## 문제

## 입력 예시

```text

```

## 출력 예시

```text
Kim
Nara
```

## 풀이 전 질문

- `split`의 결과 자료형은 무엇인가?

# 중급 5문제

# 고급 5문제

고급 문제도 오늘까지 배운 기초 기능만 사용한다. 알고리즘 자체가 어려운 것이 아니라 **여러 조건을 정확히 구현하는 연습**이다.

## 고급 1 — 태그 정리

## 문제

문자열은 `red|blue|green`처럼 `|`로 단어가 구분되어 있다.

다음을 출력하라.

1. 단어 개수
2. 첫 단어
3. 마지막 단어

## 입력 예시

```text
red|blue|green
```

## 출력 예시

```text
3
red
green
```

## 풀이 전 질문

- 한 번의 `split`로 어떤 정보를 모두 얻을 수 있는가?
- 결과 List에서 필요한 위치는 무엇인가?

---

## 고급 2 — 마스킹된 코드

## 문제

길이가 8 이상인 코드 문자열이 주어진다. 앞 네 글자는 그대로 두고, 나머지 모든 글자를 `*`로 바꾸어 출력하라.

## 입력 예시

```text
ABCD1234
```

## 출력 예시

```text
ABCD****
```

## 제한

반복문을 사용해도 되고 문자열 곱셈을 사용해도 된다.

## 풀이 전 질문

- 앞 네 글자는 어떤 slice인가?
- 가려야 할 글자 수는 전체 길이에서 얼마를 빼면 되는가?

---

## 고급 3 — 단어별 특정 문자 개수

## 문제

한 줄에 여러 단어가 공백으로 주어진다. 각 단어마다 문자 `a`가 몇 번 등장하는지 한 줄씩 출력하라.

## 입력 예시

```text
apple banana cat
```

## 출력 예시

```text
1
3
1
```

## 풀이 전 질문

- 먼저 무엇으로 단어 List를 만들 것인가?
- 각 단어에 어떤 연산을 반복해야 하는가?

---

## 고급 4 — 첫 구분자 기준으로 나누기

## 문제

문자열 안에는 `#`이 한 번 이상 존재한다. 첫 `#`을 기준으로 왼쪽 부분과 오른쪽 부분을 각각 한 줄에 출력하라.

## 입력 예시

```text
abc#def#ghi
```

## 출력 예시

```text
abc
def#ghi
```

## 풀이 전 질문

- 첫 `#` 위치는 어떻게 찾을 수 있는가?
- 찾은 위치를 이용해 왼쪽과 오른쪽을 어떤 slice로 만들 수 있는가?
- `#` 자체는 결과에서 제외하려면 시작 위치에 무엇을 더해야 하는가?

---

## 고급 5 — 간단한 로그 분석

## 문제

로그 문자열은 다음과 같이 공백으로 구분된 단어들로 구성된다.

```text
INFO login ERROR retry ERROR
```

다음을 출력하라.

1. 전체 단어 개수
2. `ERROR` 단어 개수
3. 문자열 전체에서 첫 `ERROR`가 시작되는 문자 인덱스

`ERROR`가 없으면 세 번째 줄에 -1을 출력한다.

## 입력 예시

```text
INFO login ERROR retry ERROR
```

## 출력 예시

```text
5
2
11
```

## 풀이 전 질문

- 단어 개수는 `split` 결과로 어떻게 얻는가?
- `ERROR` 단어 개수를 반복문과 조건문으로 셀 수 있는가?
- 첫 문자 위치를 찾기 전에 어떤 검사가 필요한가?
- 문자열 전체를 여러 번 선형 탐색해도 전체 Big O가 왜 `O(N)`으로 정리되는가?

# 제출 전 체크리스트

각 문제를 풀 때 다음을 확인한다.

- [ ] 문자열과 숫자를 혼동하지 않았다.
- [ ] 인덱스 범위가 맞다.
- [ ] slice 끝 위치가 제외된다는 것을 반영했다.
- [ ] `split` 결과가 List임을 알고 사용했다.
- [ ] `replace` 반환값을 저장했다.
- [ ] `count`와 `index`를 역할에 맞게 골랐다.
- [ ] `index` 대상이 없을 가능성을 확인했다.
- [ ] 최소 입력 반례를 직접 실행했다.
