# 오늘의 핵심 산출물 — if 조건 누락 체크

문제에서 조건문이 나오면 아래 순서로 확인한다.

## 1. 경계 단어 표시

문제의 다음 표현에 밑줄을 긋는다.

```text
이상
초과
이하
미만
같다
다르다
모두
하나라도
그 외
```

## 2. 구간 표 작성

예:

| 점수 | 등급 |
|---|---|
| 90 이상 | A |
| 80 이상 90 미만 | B |
| 60 이상 80 미만 | C |
| 60 미만 | F |

## 3. 경계값 한 칸씩 테스트

```text
90, 89
80, 79
60, 59
```

## 4. 겹침 검사

한 입력이 두 결과에 동시에 들어가면 안 되는 문제인지 확인한다.

## 5. 누락 검사

어떤 입력도 아무 분기에도 들어가지 않는 구간이 없는지 확인한다.

## 6. 조건 순서 검사

더 구체적인 조건이 더 일반적인 조건에 가려지지 않는지 확인한다.

예:

```text
90 이상
60 이상
```

이라면 일반적으로 90 이상을 먼저 검사한다.

# 오늘 외울 템플릿 여부

## 조건문 기본형

```python
if condition_a:
    ...
elif condition_b:
    ...
else:
    ...
```

문법보다 중요한 것은 **조건 순서와 범위**다.

## N번 반복 기본형

```python
for _ in range(n):
    ...
```

## 누적 합 기본형

```python
total = 0

for _ in range(n):
    value = int(input())
    total += value
```

## 개수 세기 기본형

```python
count = 0

for _ in range(n):
    value = int(input())

    if condition:
        count += 1
```

# 오늘의 시간복잡도

| 패턴 | 복잡도 | 이유 |
|---|---|---|
| 변수 몇 개 계산 | O(1) | 작업 횟수가 일정함 |
| if 조건 몇 개 검사 | O(1) | 조건 개수가 입력 크기와 함께 늘지 않음 |
| N번 반복 | O(N) | 반복 횟수가 N에 비례 |
| N번 안에서 다시 N번 반복 | O(N²) | 대략 N 곱하기 N번 작업 |

Day 2에서는 주로 `O(1)`과 `O(N)`을 코드에서 직접 구분한다.

# 오늘의 핵심 반례

## 반례 1 — 정확한 경계

```text
60 이상
```

이면 반드시 60을 테스트한다.

## 반례 2 — 경계 바로 아래

60 이상이면 59도 테스트한다.

## 반례 3 — 반복 1회

`N = 1`일 때도 정상 동작하는지 본다.

## 반례 4 — 조건을 한 번도 만족하지 않음

카운터가 0으로 남아도 정상인지 확인한다.

## 반례 5 — 모든 입력이 조건을 만족

카운터가 정확히 N까지 증가하는지 확인한다.
