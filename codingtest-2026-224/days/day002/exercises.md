# 고급 2 — 연속 출석 보너스

## 문제

첫 줄에 `N`이 주어진다. 다음 `N`줄에는 각 날의 출석 여부가 `1` 또는 `0`으로 주어진다.

점수 규칙:

- 결석 `0`: 그날 0점, 연속 출석 수를 0으로 초기화
- 출석 `1`: 연속 출석 수를 1 증가시키고, 그 연속 출석 수만큼 점수 획득

총점을 출력하라.

예를 들어 출석 기록이 `1, 1, 0, 1`이라면 획득 점수는 `1 + 2 + 0 + 1 = 4`다.

## 입력 예시

```text
4
1
1
0
1
```

## 출력 예시

```text
4
```

## 제한

```text
1 <= N <= 100000
```

## 풀이 전 질문

- 매일 기억해야 하는 상태는 무엇인가?
- 결석했을 때 어떤 변수를 초기화해야 하는가?

- 2의 배수이면 1점 추가


```text

6 → 1점 + 2점
```

## 제한

```text
1 <= N <= 100000
```

# 고급 4 — 제한 횟수 시뮬레이션

## 문제

정수 `value`, 목표 `target`, 최대 횟수 `K`가 주어진다.

한 번의 작업에서:

- `value`가 짝수면 3을 더한다.
- `value`가 홀수면 2를 더한다.

최대 K번 작업하면서 처음 `value >= target`이 되는 작업 횟수를 출력하라. K번 안에 도달하지 못하면 `-1`을 출력한다.

처음부터 목표 이상이면 0을 출력한다.

## 입력 예시

```text
5 12 4
```

## 진행

```text
0회 5
1회 7
2회 9
3회 11
4회 13
```

## 출력 예시

```text
4
```

## 제한

```text
0 <= value <= target <= 1000000
1 <= K <= 100000
```

## 풀이 전 질문

- 반복을 언제 종료해야 하는가?
- 목표 도달과 K회 소진 중 어떤 조건을 먼저 확인하는가?

# 고급 5 — 다단계 자격 판정

## 문제

지원자의 `age`, `score`, `training`이 주어진다.

아래 순서대로 **정확히 하나의 결과**를 출력한다.

1. `age`가 18 미만이면 `AGE_FAIL`
2. 그렇지 않고 `score`가 80 이상이며 `training`이 100 이상이면 `VIP`
3. 그렇지 않고 `score`가 60 이상이며 `training`이 50 이상이면 `PASS`
4. 그 외에는 `FAIL`

## 입력 예시

```text
20 85 120
```

## 출력 예시

```text
VIP
```

## 제한

```text
0 <= age <= 120
0 <= score <= 100
0 <= training <= 1000
```

## 풀이 전 질문

- 왜 나이 조건을 먼저 검사해야 하는가?
- `VIP` 조건과 `PASS` 조건은 겹치는가?
- 겹친다면 어떤 조건을 먼저 검사해야 하는가?
