# Day 4 풀이 폴더

Day 4의 실습과 연습문제 코드는 이 폴더에 작성한다.

## 실습

```text
practice01.py
practice02.py

practice04.py

```

## 연습문제

```text
beginner01.py ~ beginner05.py
intermediate01.py ~ intermediate05.py
advanced01.py ~ advanced05.py
```

문제는 다음 파일에서 읽는다.

```text
days/day004/exercises.md
```

각 문제를 풀기 전에 파일 맨 위에 다음 내용을 주석으로 적는 것을 권장한다.

```text
N 범위:
유효 인덱스:
예상 시간복잡도:
위험한 경계값:
```

특히 `i + 1` 또는 `i - 1`을 사용한다면 반복 범위를 코드보다 먼저 적는다.
